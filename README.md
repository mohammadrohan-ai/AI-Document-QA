🤖 AI Document Q&A

An AI-powered document question-answering system built with Python using Retrieval-Augmented Generation (RAG). The project supports PDF and TXT documents, splits them into smaller chunks, generates semantic embeddings using Sentence Transformers, and uses cosine similarity to retrieve the most relevant content. The retrieved information is then provided to Google Gemini to generate clear and context-based answers. 📄🧠🔍🤖

✨ Features
📄 PDF & TXT document support
📚 Multiple document support
✂️ Automatic text chunking
🧠 Semantic embeddings
🔍 Top-3 relevant chunk retrieval
🤖 Gemini-powered answer generation
💻 Simple command-line interface
🛠️ Technologies

Python • Google Gemini API • Sentence Transformers • Scikit-learn • PyMuPDF • python-dotenv

🎯 Purpose

Built as a practical project to understand the fundamentals of RAG, embeddings, semantic search, cosine similarity, document processing, and LLM integration.
